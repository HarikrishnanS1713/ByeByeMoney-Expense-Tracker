# 💰 ByeByeMoney – Personal Expense Tracker

A simple and interactive personal expense tracking web application that helps users manage daily expenses, monitor spending habits, and visualize financial activities through interactive charts.

## 🌟 Features

- **Add Expenses:** Record expenses with amount, category, description, and date.
- **Expense Management:** View and delete recorded expenses.
- **Dashboard Analytics:** Track total spending, monthly spending, total expenses, and average daily spending.
- **Category Analysis:** Visualize expenses using an interactive doughnut chart.
- **Monthly Spending Trends:** Monitor spending patterns using a line chart.
- **Search Expenses:** Search expenses by description or category.
- **Filter Expenses:** Filter transactions based on expense categories.
- **Export Data:** Download expense records in JSON format.
- **Local Storage:** Save expense records directly in the browser.

## 🚀 Getting Started

### Prerequisites

- A modern web browser.
- Visual Studio Code (optional).

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/HarikrishnanS1713/ByeByeMoney-Expense-Tracker.git
   ```

2. Navigate to the project directory:

   ```bash
   cd ByeByeMoney-Expense-Tracker
   ```

3. Open `index.html` in your browser.

You can also use the VS Code Live Server extension to run the application locally.

## 💾 Data Storage

This application uses browser LocalStorage to save expense records.

**Note:** Expense records are stored locally in the browser and are not synchronized across different browsers or devices. Clearing browser storage may remove saved records.
